# My Productivity Dashboard

A simple personal dashboard for keeping track of what you want to get done **today**, **this week**, and your bigger **goals**. It works on a computer and on an iPhone.

My first project built with Claude Code.

## What it does

- **Three lists:** Today, This Week, and Goals
- **Add a task:** type in the box at the bottom of a list, then press Enter or tap **+**
- **Mark a task complete:** tap the circle (or the task's name). Tap again to undo.
- **Delete a task:** tap the **×** on the right
- **Today's progress:** the ring shows what percent of today's tasks are done
- **Saves automatically:** your tasks stay put when you refresh or close the page
- **Light and dark mode:** follows your device's setting
- **Sample tasks:** the first time you open it you'll see example tasks. Delete them, or use **Reset to sample tasks** at the bottom to bring them back.

## How to open it

You don't need to install anything.

1. On this repository's GitHub page, click the green **Code** button → **Download ZIP**.
2. Unzip the downloaded file.
3. Double-click **`index.html`**. It opens in your web browser.

## How to use it on your iPhone (optional)

The easiest way is to let GitHub host it for free with **GitHub Pages**:

1. On GitHub, open this repository → **Settings** → **Pages**.
2. Under **Branch**, choose the branch with the app on it (for example `main`) and the `/ (root)` folder, then click **Save**.
3. After a minute or two, GitHub shows a link like `https://YOUR-USERNAME.github.io/my-first-claude-project/`.
4. Open that link in Safari on your iPhone. To use it like an app, tap **Share** → **Add to Home Screen**.

> **Good to know:** tasks are saved *in each browser separately*. Tasks you add on your computer won't show up on your iPhone, and clearing your browser's data erases them.
